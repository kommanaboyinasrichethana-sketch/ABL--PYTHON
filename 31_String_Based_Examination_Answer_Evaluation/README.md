# Running and Testing This Project

1. Open a terminal in this folder.
2. Run: `python main.py`
3. Enter one answer for each question. Use A, B, C, D, or X for blank.
4. Capture a screenshot of the terminal output for your assignment report.

## Suggested additional tests
- Enter lowercase answers (for example, `a`) to confirm they are accepted.
- Enter an invalid response (for example, `Z`) and confirm the program asks again.
- Test all correct, all incorrect, and all unanswered responses.
