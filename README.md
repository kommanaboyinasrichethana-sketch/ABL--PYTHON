# Python Activity-Based Learning (ABL)

First-year engineering Python ABL assignment based on the Unit I–III syllabus.

## Project structure

Each case study has its own folder. Every project folder contains the Python source code and documentation needed for the assignment.

### Selected case studies
1. *Railway Fare Reservation Calculator.
2. *Manufacturing Cost Profitability.
3. *Attendance Recovery Computation.
4. *Fule Consumption Route Comparison.
5. *Traffic Violation Penalty Calculator.
6. *Advanced Numeric Pattern Generator.
7. *Password Policy Validation.
8. *Text Compression Character Runs.
9. *Student Marks Matrix Analysis.
10. *Tuple Product Catalogue Andit.

## How to run a program

1. Install Python 3.
2. Open a terminal in the required project folder.
3. Run the program with `python main.py` (or use the filename shown in that folder).
4. Follow the prompts and compare the result with the documented test cases.

## Documentation included

Each completed project aims to include: problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, source code, test cases, sample output, and conclusion.
